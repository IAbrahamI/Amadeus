# Your notes

This folder is where you and Amadeus share notes. They're plain Markdown files, so open them in any app you like.

- **ToDo.md** and **Notes.md** are yours. Amadeus adds or ticks off items only when you ask, and only after you approve.
- **_Amadeus/** belongs to the assistant. It keeps it tiny.
- Work projects for Claude Code are **not** here: they have their own folder next to this one, so a work run never sees your notes.

Every hour a snapshot of this folder is saved in `~/.local/share/amadeus/notes-snapshots/`, so any change can be undone.
